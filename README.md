# N. Murata の研究の地図

N. Murata (村田 昇，早稲田大学) の論文を，内容・引用・共著の近さで 2 次元・3 次元の地図にしたものです．
関係の深い他の著者の文献と，村田研究室の修士論文も同じ地図に重ねて表示できます．

**ページ**: <https://noboru-murata.github.io/research-map/>
(`index.html` だけで動きます．ネットへの接続も外部のライブラリも使いません．手元に置いたファイルを開いても動きます．)

| 載せているもの | 件数 | 印 |
|---|---|---|
| 村田の論文 (雑誌・国際会議) | 150 | ● (要旨・本文あり) ○ (題のみ) |
| 関係の深い他の著者の文献 | 180 | ◇ |
| 村田研究室の修士論文 (2002〜2025 年度) | 119 | ▲ |

## 使い方

- **地図を作る**: 枠の上で，次元 (2D / 3D)，乖離度 (下の表)，変換，当てはめ方を選びます．
  既定は 3 次元の Isomap (k = 8 の近傍の測地距離 + 古典的 MDS) で，乖離度は概念辞書です．
- **見る**: ホイールで拡大，ドラッグで移動 (3D では回転．Shift + ドラッグで移動)，ダブルクリックで元に戻します．
  3D では「回転」で回し続け，「正面・横・斜」で視点を選べます．
- **調べる**: 点にマウスを載せると題と著者，クリックすると右の欄に詳細と乖離度で近い文献を出します．
  Shift + クリックで 2 点目を選ぶと，2 点の間の乖離度を尺度ごとに並べます．検索の欄は題・著者・概念で探します．
- **色分け**: 主題 (概念辞書の大分類)，話題 (NMF)，年，出典，主な共著者，主題の重み．凡例のクリックで表示・非表示，ダブルクリックでそれだけを表示します．
- **年**: スライダーと ▶ で，その年までに出た文献だけを濃く表示します (研究の広がりを順に見る)．
- **重ねる**: 左の欄で関連文献 (◇) と修士論文 (▲) を表示します．関連文献は「村田の論文の何本以上に引かれているか」と「題・要旨の近さの上位何件か」で絞ります．
  「引用の線」で引用でつながる文献を結びます．
- **比べる**: 「2 枚で比べる」で二つの地図を並べます (B は Procrustes 回転で A に向きをそろえ，点は両方で連動して光ります)．
  「乖離度どうしの比較」で，尺度の間の順位相関と近傍の重なりを表にします．
- **スマートフォン・タブレット** (幅 900px 以下): 地図が画面いっぱいになり，「≡ 設定」で色分け・表示・重ね表示の引き出しを，「詳細」で下からの詳細の欄を開きます．
  1 本指のドラッグで回転 (2D では移動)，2 本指で拡大・縮小，点のタップで詳細，背景の素早い 2 回のタップで元の視点に戻ります．
- **URL での指定**: `?layout=2&a=concept&b=lsa&ad=3&bd=2&am=tsne&at=none&color=year&rel=1&th=1&theme=light` のように，
  枠 A・B の乖離度 (`a`，`b`)，次元 (`ad`，`bd`)，当てはめ方 (`am`，`bm`: cmds，smacof，nmds，sammon，tsne)，
  変換 (`at`，`bt`: none，geo，rank)，色分け，関連文献 (`rel=1`)，修士論文 (`th=1`)，明るい表示 (`theme=light`) を選べます．

## 乖離度 (文献の間の違いの測り方)

| 乖離度 | 系統 | 定義 | 件数 |
|---|---|---|---|
| 題・要旨の語 | 語彙 | 題・要旨・キーワードの TF-IDF ベクトルの余弦距離 1 − cos | 150 |
| 全文の潜在意味 (LSA) | 語彙 | 本文 (参考文献を除く) の TF-IDF 行列を特異値分解した上位 20 次元の余弦距離 | 139 |
| 話題の割合 | 確率分布 | 本文の非負値行列因子分解 (12 話題) の話題の割合 θ の Hellinger 距離 √(1 − Σ√(θᵢθⱼ)) | 139 |
| 語の分布 | 確率分布 | 本文の語の多項分布 (全体の分布と 7 : 3 で混ぜて平滑化) の Jensen–Shannon 情報量の平方根 | 139 |
| 概念辞書 | 概念 | 手で作った概念辞書 (114 概念，20 主題．英語と日本語の表記) の出現頻度 (1000 語あたり，log，IDF) の余弦距離 | 150 |
| 参考文献の重なり | 引用 | 参考文献の節を文献データベースの題と照合した引用集合の Salton 余弦距離 1 − \|A∩B\|/√(\|A\|\|B\|) (書誌結合) | 67 |
| 共著者の重なり | 人 | 著者の集合の Jaccard 距離 1 − \|A∩B\|/\|A∪B\| | 150 |

- 内容の尺度 (概念辞書・LSA・語の分布・書誌結合) どうしは順位相関 0.4〜0.75 でおおむね一致し，共著者は 0.3 前後で別の軸です．
  概念辞書は他の尺度との一致が最もよく，日本語の修士論文も同じ軸で測れるので既定にしています．
- **混合**: 乖離度を重みつきで足します (それぞれ共通の文献の組の平均を 1 にそろえてから)．
- **変換**: そのまま / 測地 (k 近傍のグラフの最短路の長さ．Isomap の考え方) / 順位 (全ての組の順位に置き換える)．

## 当てはめ方

| 方法 | 内容 |
|---|---|
| 古典的 MDS | 乖離度の二乗を二重中心化した内積行列の上位の固有ベクトル．測地の変換と組むと Isomap |
| 計量的 MDS (SMACOF) | ストレス Σ(dᵢⱼ − δᵢⱼ)² を Guttman 変換の反復で減らす |
| 非計量 MDS | δ の大小の順序だけを保つ (Kruskal．単調回帰と SMACOF の交互) |
| Sammon | 近い組の誤差を重く見る Σ(dᵢⱼ − δᵢⱼ)²/δᵢⱼ |
| t-SNE | 近傍の確率 (ガウス) と地図の確率 (t 分布) の KL 情報量を減らす．塊の間の距離は読めない |

枠の下に当てはまりを出します: ストレス (尺度をそろえた後の相対誤差)，10 近傍の保存 (乖離度で近い 10 件が地図でも近い 10 件に入る割合)，順位相関 (乖離度と地図の距離)．

## 関連文献と修士論文の置き方

村田の論文の地図は動かさず，重ねる文献から村田の論文への乖離度だけを (村田の論文で作った語彙・特異値分解・話題・概念辞書のまま) 計算して後から置きます．

- **B 差し込み**: 古典的 MDS は Gower の公式で厳密に，SMACOF・Sammon は 1 点の Guttman 変換，非計量 MDS は単調回帰の当てはめ値に合わせて，
  t-SNE は村田の論文だけで作った近傍の確率との KL 情報量を 1 点について減らして置きます．
- **C 引用の重心**: その尺度にデータが無い文献は，引用でつながる村田の論文 (関連文献ならそれを引いている論文，修士論文ならそれが引いている論文) の重心に置きます．
- **D 概念の重心**: それも無ければ，概念辞書で近い村田の論文 5 本の重心に置きます．
- **E 対応分析**: 乖離度の選択肢の最後．「村田の論文 × 2 本以上に引かれている関連文献」の 0/1 の表を対応分析 (数量化 III 類) にかけ，論文と文献を同じ空間に置きます．

関連文献は，村田の論文の 2 本以上に引かれている文献と，題・要旨の TF-IDF で村田の論文に近い文献 (上位 100 件) です．
修士論文はほとんどが日本語なので，概念辞書・参考文献の重なり・共著者で測り，英文のものだけ英語の語の尺度も使います．
修士論文は姓・題目・年度だけを表示します．

## データについて

- 村田の論文は，雑誌と国際会議の論文です (書籍の章・著書・講義資料・訂正記事は除く)．書誌情報は村田の文献データベース (Zotero) と Scopus から取りました．
- 要旨と本文は乖離度の計算にだけ使い，このリポジトリには入れていません (要旨の著作権は多くの場合出版社にあるため)．各文献は DOI のリンクから原典へ進めます．
- 修士論文は本文から乖離度を計算し，このリポジトリには姓・題目・年度と配置の数値だけを入れています．
- 参考文献の照合，概念辞書，PDF からの文字の取り出しは自動の処理なので，取りこぼしや誤りがあります．

# N. Murata の研究の地図

N. Murata (村田 昇) の論文 150 件を，内容・引用・共著の近さで地図にしたものです．
関係の深い他の著者の文献 180 件も重ねて表示できます．

**ページ**: GitHub Pages で `index.html` を開きます (ネットは要りません．ファイルを手元で開いても動きます)．

## 何を見ているか

文献の間の「違い」(乖離度) を何通りか作り，多次元尺度構成法などで 2 次元・3 次元の地図にしています．

| 乖離度 | 定義 | 件数 |
|---|---|---|
| 題・要旨の語 | 題と要旨の TF-IDF の余弦距離 | 150 |
| 全文の潜在意味 (LSA) | 本文の TF-IDF を特異値分解した 20 次元の余弦距離 | 139 |
| 話題の割合 | 本文の NMF (12 話題) の割合の Hellinger 距離 | 139 |
| 語の分布 | 本文の語の分布 (平滑化) の Jensen–Shannon 距離 | 139 |
| 概念辞書 | 手で作った概念辞書 (96 概念，18 主題) の出現頻度の余弦距離 | 150 |
| 参考文献の重なり | 書誌結合 (引いている文献の集合の Salton 余弦距離) | 67 |
| 共著者の重なり | 著者の集合の Jaccard 距離 | 150 |

- 当てはめ方: 古典的 MDS，計量的 MDS (SMACOF)，非計量 MDS，Sammon，t-SNE．変換 (測地・順位) と，乖離度の重み付きの混合も選べます．
- 「2 枚で比べる」で二つの地図を並べ (Procrustes で向きをそろえる)，「乖離度どうしの比較」で尺度の一致を見られます．
- 関連文献 (◇): 村田の論文の 2 本以上に引かれている文献と，題・要旨が近い文献．村田の論文の地図は動かさずに後から差し込み，
  引いている論文と点線で結びます．「E: 対応分析」では，論文 × 引用文献の表から両方を同じ空間に置きます．

## データについて

- 文献の情報 (題・著者・年・掲載先・DOI) は村田の文献データベースと Scopus から取りました．
- 要旨と全文は乖離度の計算にだけ使い，このリポジトリには入れていません．
- 雑誌と国際会議の論文だけを対象にしています (書籍の章・著書・講義資料は除く)．
